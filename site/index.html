Desktop app for macOS and Linux

Learn system design from scratch

Each topic starts with a lesson, a quiz checks it, and remediation lessons close the gaps until you master the topic. Then you practise on a diagram canvas, with the steps of an interview introduced one at a time. Everything is generated for you by the Claude Code CLI from the System Design Primer, and everything stays on your machine.

A session, step by step

This is the flow of a real session, in the order you live it. The content in the screenshots was generated by the app, not written for the page. Select a screenshot to open it full size.

1Follow the Learning Path

The path runs from a Foundations Module (how the web works, networking, storage, orders of magnitude) through the topics of the primer to the Design Exercises. Each step unlocks once the previous one is mastered, so you always know what to do next.

You are not stuck behind a lock. I already know this declares a topic as mastered without a quiz, and Unlock anyway opens a locked step without credit. Both are visible on the path and can be undone.

2Read a lesson

A lesson is written for a complete beginner, one section per notion, and grounded on the primer: every claim cites its source section, and diagrams show the request flow or the architecture being explained.

Select a passage you do not follow and ask about it. The answer comes from the lesson and the primer, and says so plainly when the question goes beyond the course.

3Take the quiz, then close the gaps

The quiz mixes single choice, multiple choice, trade-off scenarios and short free answers graded by the model. Choice questions are graded on your machine, and every answer comes with its explanation.

If a question is unclear, I don’t understand the question rewords it with an example, without hinting at the answer. When a round is not enough, a short remediation lesson explains the missed notion from another angle, then a new round asks fresh questions. That is the Mastery Loop, and the threshold is yours to set.

4Design on a canvas

A Design Exercise gives you a problem and a canvas with typed components (client, CDN, load balancer, service, cache, database, queue). You work through the steps of an interview protocol, introduced progressively: functional requirements, estimations, high-level design, and more as you go.

Submit a step to get feedback on what you drew and wrote, ask for graded hints that never give the answer away, and finish with a review against the primer’s own solution.

5See where you stand

The Dashboard lists the topics mastered, your attempts and accuracy, and the weak points to practise. The Notion Map shows the latest score of every notion, with a symbol as well as a color.

Download

Packaged apps are attached to every GitHub Release; the latest one is always the page to start from. Personal use: the macOS app is not notarized. The app checks for a newer release at launch and installs it in one click on macOS and on a Linux AppImage (a .deb only announces it). Each release has a SHA256SUMS file.

macOS (Apple Silicon)

One command, no Gatekeeper dialog. It installs the latest release into /Applications: 

curl -fsSL https://raw.githubusercontent.com/jbclaramonte/system-design-from-scratch/main/install.sh | bash

It downloads the .dmg with curl, checks its checksum and copies the app. Run it again to update. Read install.sh before piping it to a shell.

Linux (x64)

The same command, no sudo. It detects Linux and installs the AppImage:

curl -fsSL https://raw.githubusercontent.com/jbclaramonte/system-design-from-scratch/main/install.sh | bash

It checks the checksum, installs the AppImage in ~/.local/share/system-design-from-scratch/ and adds a launcher, so the app appears in the application menu. Without FUSE 2 it prints the fix (sudo apt install libfuse2) and writes a launcher that extracts the app on each start. Ubuntu 22.04 is the oldest supported release; on Ubuntu 24.04, which restricts the sandbox of an AppImage, use the .deb.

Install with Claude Code

Already in Claude Code? Paste this prompt: it reads the script, tells you what it does, then installs the app. 

Install "System Design from Scratch" on this machine for me, step by step.
1. Detect my OS and CPU architecture (uname -s, uname -m). Supported: macOS on Apple Silicon (arm64) and Linux x64 (x86_64). On anything else, stop and tell me plainly that it is not supported.
2. Download https://raw.githubusercontent.com/jbclaramonte/system-design-from-scratch/main/install.sh, read all of it, and give me a short summary of what it does before you run it.
3. Run it with bash, without sudo. On macOS it installs into /Applications; on Linux into ~/.local/share/system-design-from-scratch, with an application-menu launcher. Show me its output. If it fails, explain the error: do not retry blindly or work around it.
4. Check that the Claude Code CLI (claude) is installed and logged in (for example claude --version and claude auth status). If not, tell me the exact step I must do myself: logging in is interactive, so I run it here with "! claude". Never ask for or handle my credentials.
5. Tell me how to launch the app, that my data lives in ~/Library/Application Support/system-design-from-scratch (macOS) or ~/.config/system-design-from-scratch (Linux), and how updates work: the app checks at launch and updates itself in one click on macOS and on the Linux AppImage.
Never touch my data folder or anything outside the install locations.

Requirements

  • Claude Code CLI

    The Claude Code CLI must be installed and logged in: the app drives it for every generation. The Settings screen has a Test button that tells you if it is found and logged in.

  • Course language

    The app asks at the first launch whether the course is written in French or in English. In French, system design terms stay in English as they are said in interviews. You can switch in Settings; content already generated is kept, and your progress does not depend on the language.

  • Platform

    macOS on Apple Silicon, or Linux x64. Generations run on your own Claude plan.

What it is not

  • Not a service

    No account, no server, no cloud sync. Your progress lives in a local SQLite file.

  • No telemetry

    The app sends nothing about you anywhere. Its only network use is the Claude Code CLI you run.

  • Not an oracle

    Lessons, quizzes and feedback are written by a language model. They cite the primer so you can check, and they can still be wrong.
