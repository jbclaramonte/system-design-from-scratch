# Foundations Module

Prerequisite topics absent from the primer (client/server, HTTP, DNS, basic databases). Generated from the model's own knowledge, so it is ungrounded and flagged as such in the UI. First stage of the [[Learning Path]].

## Related

- First stage of the [[Learning Path]]
- Ungrounded, see [[Grounding]]

## In code

Ungrounded prompt variants (no excerpts, no citations, `grounded: false`) for every content prompt, chosen from `topics.in_foundations_module` by `topicGrounding` (`src/main/generation/pipelines.ts`). See [[Prompts]]. The module's topics themselves are not seeded yet (#16).
