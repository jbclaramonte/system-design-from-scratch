# Diagram

A Mermaid schema embedded in generated content as a ```` ```mermaid ```` block (architecture, request flow, data model, state machine), drawn in the app as an SVG, or shown as its source with a short note when it cannot be drawn. Not something the learner draws: that is the [[Design Canvas]].

## Related

- Part of a [[Lesson]], a [[Remediation Lesson]] or a [[Protocol Step Lesson]] (generated by #23), and of scenario [[Question|Questions]] (#24)
- Not a [[Design Graph]] (the structured export of a [[Design Scene]])

## In code

`src/renderer/src/markdown/`: `MermaidDiagram` draws one, `MarkdownContent` draws those of a Markdown text, `diagramSource.ts` holds the checks and limits. See [[Mermaid Diagrams]].
